`ContourDigits-Black.ttf` is a modified version of Orbitron Black by Matt
McInerney and the Orbitron Project Authors (https://github.com/theleagueof/orbitron),
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
The changes are a plain zero instead of the slashed one and an 8 drawn from scratch (two thin slot counters, small V notches at the sides) and rounded corners everywhere; it is renamed
because "Orbitron" is a Reserved Font Name. `tools/font/make_digits.py`
rebuilds it. Only the digits are built into the watchface.
